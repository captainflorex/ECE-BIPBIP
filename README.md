# ECE-BIPBIP
(FR) Code final du projet de 1ere année de prepa integrée, "ECE BIPBIP".
Ce projet consiste concretement a fabriquer un objet pour comuniquer avec un autre objet, appelé des bippeurs.

(EN) Final code of the first year of engineer school "ECE BIPBIP".
