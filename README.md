# ECE-BIPBIP
🇫🇷 Français
Code final du projet de 1ère année de prépa intégrée — ECE BIPBIP

Ce projet a pour objectif de concevoir et réaliser un dispositif électronique capable de communiquer avec un autre appareil similaire. Ces dispositifs, appelés bippeurs, fonctionnent comme de petits talkie-walkies permettant un échange simple et fiable entre deux unités.

🇬🇧 English
Final code of the first-year integrated preparatory program — ECE BIPBIP

This project aims to design and build an electronic device capable of communicating with another similar unit. These devices, called bippers, operate like small walkie-talkies, enabling straightforward and reliable communication between two units.
